# Port Hopper

Port Hopper operates a fictional maritime game and measures gameplay usage for billing.

## Language

**Active Play Time**:
The billable duration of a player's active gameplay, measured in whole seconds. Time spent idle with the game open is excluded.
_Avoid_: Session duration, voyage duration

**Play Session**:
A period during which Port Hopper meters one player's gameplay. It ends when the player stops or the session expires from inactivity.

**Play Time Usage Record**:
The billable Active Play Time attributed to a customer account for one finalized Play Session.
